## ✨ Ключевые возможности

- ⚡ **Несгораемые часы и ступени Пантеона**:
  - Никаких сгорающих "стриков" и штрафов за пропуски дней — только кумулятивный рост.
  - Формула прогрессии: $XP = 100 \times \text{level}^{1.5}$.
  - 10 рангов: от *Смертного* и *Искателя* до *Повелителя Олимпа*.
  - 4 божественные стихии: **Афина** (Интеллект), **Арес** (Сила & Спорт), **Гермес** (Труд & Финансы), **Аполлон** (Творчество).

- 📜 **Свиток Квестов и Секундомер Фокуса**:
  - Создание персональных квестов с гибкой наградой в XP и привязкой к стихиям.
  - Таймер фокуса с секундомером (с точностью до секунды) и звуковыми уведомлениями.

- 🏛️ **Храм Достижений**:
  - 10 легендарных триггерных достижений (Первый шаг, Олимпиец, Марафонец, Полимат и др.) с проверкой условий в реальном времени.

- 🗓️ **Календарная тепловая карта (Activity Heatmap)**:
  - Матрица продуктивности по дням года в стиле GitHub.
  - 5 уровней золотого свечения, статистика серии продуктивности и интерактивная подсказка с разбивкой по активностям за каждый день.

- 🎉 **Праздничные микроанимации и звуки**:
  - Синтезированные звуковые эффекты на Web Audio API (без внешних аудиофайлов, 0 мс задержки).
  - Победный салют конфетти (`canvas-confetti`) при взятии уровней и завершении квестов.
  - Переключатель звука в шапке.

- 🎴 **Экспорт Карточки Героя (1200×630 HD)**:
  - Генерация античной карточки героя через HTML5 Canvas с возможностью выбрать до 5 лучших наград.
  - Скачивание PNG в один клик для публикации в соцсетях и мессенджерах.

- 💾 **100% Офлайн и Приватность (PWA & JSON Backup)**:
  - База данных Dexie.js (IndexedDB) работает полностью в браузере.
  - Резервное копирование и восстановление всей истории в JSON с умным слиянием дубликатов.
  - Установка на главный экран смартфона или ПК в один клик.

## 🚀 Быстрый старт

### Требования
- Node.js >= 18
- pnpm (или npm / yarn)

### Установка и локальный запуск
```bash
# Клонирование репозитория
git clone https://github.com/<ваш-логин>/life-gamification.git
cd life-gamification

# Установка зависимостей
pnpm install

# Запуск dev-сервера
pnpm dev
```
Откройте [http://localhost:5173](http://localhost:5173) в браузере.

### Проверка тестов и сборка
```bash
# Запуск тестов (80 тестов)
pnpm test

# Проверка типов TypeScript
pnpm typecheck

# Продакшн-сборка
pnpm build
```
