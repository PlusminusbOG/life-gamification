# Руководство по бесплатному развертыванию (Деплою) и шарингу

Приложение **«Герой Эллады» (Life Gamification)** разработано как автономное PWA (Progressive Web Application). Вся база данных хранится локально в браузере пользователя (IndexedDB), поэтому приложению **не требуется платный бэкенд или база данных**. Вы можете разместить его на любом бесплатном статическом хостинге с 100% аптаймом и нулевыми затратами.

---

## 🚀 Вариант 1: GitHub Pages (Рекомендуемый, бесплатно навсегда)

В репозитории уже настроен автоматический пайплайн **GitHub Actions** (`.github/workflows/deploy.yml`), который при каждом пуше автоматически проверяет типы, прогоняет 80+ тестов, собирает продакшн-бандл и публикует сайт.

### Шаги настройки:
1. **Создайте репозиторий на GitHub** (если еще не создан):
   ```bash
   git init
   git add .
   git commit -m "feat: complete life gamification app"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_АККАУНТ>/<ИМЯ_РЕПОЗИТОРИЯ>.git
   git push -u origin main
   ```

2. **Включите GitHub Pages через Actions**:
   - Перейдите в ваш репозиторий на GitHub.
   - Откройте вкладку **Settings** (Настройки).
   - В левом меню выберите раздел **Pages**.
   - В пункте **Source** (Источник) выберите:
     👉 **GitHub Actions** (вместо "Deploy from a branch").

3. **Готово!**
   - GitHub Actions автоматически запустит деплой (статус виден во вкладке **Actions**).
   - Через 1–2 минуты ваше приложение станет доступно по ссылке:
     `https://<ВАШ_АККАУНТ>.github.io/<ИМЯ_РЕПОЗИТОРИЯ>/`

## ⚡ Вариант 2: Vercel (Мгновенный деплой в 1 клик)

Vercel предоставляет бесплатный глобальный CDN и автоматический HTTPS.

1. Перейдите на [vercel.com](https://vercel.com) и войдите через GitHub.
2. Нажмите **Add New...** → **Project**.
3. Выберите ваш репозиторий с проектом.
4. Настройки сборки определятся автоматически:
   - **Framework Preset**: Vite
   - **Build Command**: `pnpm build` (или `npm run build`)
   - **Output Directory**: `dist`
5. Нажмите кнопку **Deploy**.
6. Через 30 секунд вы получите персональный домен вида:
   `https://life-gamification-<hash>.vercel.app`

---

## 🌐 Вариант 3: Cloudflare Pages (Максимальная скорость CDN)

1. Зайдите в панель [dash.cloudflare.com](https://dash.cloudflare.com/) → раздел **Workers & Pages**.
2. Нажмите **Create application** → вкладка **Pages** → **Connect to Git**.
3. Выберите репозиторий.
4. Укажите параметры:
   - **Framework preset**: `Vite`
   - **Build command**: `pnpm build`
   - **Build output directory**: `dist`
5. Нажмите **Save and Deploy**.
6. Сайт доступен по адресу вида: `https://<проект>.pages.dev`.

## 📱 Инструкция для друзей: Как запускать и играть

Отправьте друзьям полученную ссылку. Они смогут пользоваться всеми возможностями:

1. **Установка на телефон или рабочий стол (PWA)**:
   - **Android / Chrome / Яндекс.Браузер**: Нажать на меню (три точки) или значок в поисковой строке → **«Установить приложение»** или **«Добавить на главный экран»**.
   - **iOS / Safari**: Нажать кнопку «Поделиться» (квадрат со стрелкой вверх) → **«На экран "Домой"»**.
   - Приложение работает как нативное: без рамок браузера, с ярлыком на рабочем столе и **даже без интернета (в самолете, метро)**!

2. **Сохранение прогресса и приватность**:
   - Все прокачанные часы, квесты и ачивки хранятся исключительно в браузере пользователя (100% приватность, никаких трекеров).
   - В шапке приложения есть кнопка **«Резервная копия»**: можно в один клик скачать JSON-файл своего героя и восстановить его на любом другом компьютере или телефоне.

3. **Как хвастаться достижениями (Карточка Героя)**:
   - Нажав кнопку **«Карточка Героя»** в профиле, можно выбрать до 5 любимых бейджей достижений.
   - Приложение сгенерирует стильную HD-картинку (1200×630) с античным оформлением, прогрессом и текущим рангом, которую удобно отправить в Telegram, Discord, VK или выложить в сторис!

4. **Праздничные эффекты**:
   - При завершении квестов и апе уровня играет торжественный звук (Web Audio API) и запускается салют из конфетти. Звук можно выключить в любой момент переключателем в правом верхнем углу.
